| 领域测试         | 通过：上海时钟、交易日历、CSV、整数金额、成交约束、资金/回撤、会话、来源校验及 AI 解析失败                                                                                                         |

测试使用回环地址上的独立临时 PostgreSQL 和明确标注的合成数据，不读取生产连接。已验证本机中文安装路径下的 PostgreSQL 初始化问题，通过临时 ASCII share 目录别名规避；别名仅用于测试启动。

HTTP 验收发现并修正了 Next.js 内部 localhost URL 与浏览器实际 Host 不同而误拒合法登录的问题。修正后合法登录通过，跨站请求仍被拒绝，并增加了回归测试。

可复现命令及生产启用步骤见 [使用指南](PAPER_EXPERIMENT.md)。上线前仍需核对目标数据库基线、访问配置和真实行情来源，并补做桌面与手机视觉检查。
